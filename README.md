# Rainy Days

An online store website for Rainy Days, a fictional brand that sells high quality outdoor clothing.

Live [website](https://joriyx.github.io/html-css-jorgine/)

## Features

- Home page with popular products
- Shop with a grid of products
- Individual product page
- Mocked checkout functionality

## Prerequisites

- Visual Studio Code
- Live Server (VS Code extension)

## Getting Started

### Running the project

Click the 'Go Live' button in VS Code
